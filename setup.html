🔑 ตั้งรหัสทีม

ให้ทุกคนเข้าใช้งานด้วย รหัสทีม ที่คุณตั้งเอง แทนการวาง GitHub Token ทีละคน หน้านี้ทำงานในเครื่องคุณเท่านั้น ไม่ส่งข้อมูลไปที่ไหน

  1. วาง GitHub Token (ที่สร้างไว้ มีสิทธิ์ Contents: Read and write)
  2. ตั้งรหัสทีมที่ต้องการ แล้วกดสร้างไฟล์
  3. นำไฟล์ auth.json ที่ได้ไปอัปโหลดไว้ที่ root ของ repo (ข้างๆ index.html) แล้ว Commit
